# Bàu Trúc Heritage

Build a full multi-page website for a traditional Vietnamese Cham pottery workshop called "Gốm Bàu Trúc — Nghệ Nhân Đàng Xem" located in Khanh Hoa, Vietnam. The pottery is UNESCO-recognized intangible cultural heritage (2022).

---

🎨 DESIGN SYSTEM

Color palette (mandatory):
- Background: #F5EFE6 (warm cream)
- Primary text: #2C1A0E (deep espresso brown)
- Accent: #C4713A (terra cotta / burnt clay)
- Secondary accent: #8B5E3C (warm wood brown)
- Surface/card: #EDE0D0 (light sandy beige)
- Highlight: #D4A96A (warm gold — for UNESCO badge, CTAs)
- White: #FDFAF6 (off-white, not pure white)

Typography:
- Headings: serif font (Playfair Display or Cormorant Garamond) — evokes heritage, elegance
- Body: sans-serif (Inter or DM Sans) — clean readability
- All Vietnamese text must render correctly (UTF-8)

Visual style:
- Earthy, raw, artisanal — like holding a piece of hand-thrown clay
- Lots of whitespace, breathing room between sections
- Subtle textures: grain/noise overlay on hero backgrounds
- Rounded corners: minimal (4–8px only)
- No gradients — flat earthy colors only
- Photography placeholders: use warm amber/brown toned placeholder images
- Subtle horizontal dividers using terra cotta color
